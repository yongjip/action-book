# 경매

#### 경매

**1. 분석 기준 만들기**

* **분석 유형** :
  * 경매 낙찰 + 매각
  * 경매 낙찰 + 임대
* **분석 지역** :
  * 시/도, 시/구/군, 읍/면/동 단위 선택 가능
* **물건 종류** :
  * 주거용: 아파트, 단독/연립, 다가구/원룸, 다세대/빌라, 근린/상가주택, 오피스텔
  * 상업/산업용: 근린생활시설, 사무실, 지식산업센터,창고,공장,숙박시설,숙박(콘도등),목욕탕,노유자시설,문화및 집회시설,종교시설,의료시설,교육연구시설,장례관련시설,농가관련시설,주유소,자동차관련시설,분뇨 및 쓰레기처리
  * 토지: 대지, 농지(전답), 과수원,임야,잡종지,도로,주차장,묘지,목장용지,공장용지,창고용지,기타용지
* **분석 기간** :
  * 시작일 \~ 종료일
* **용도지역** :
  * **주거지역** : 제1종전용주거지역, 제2종전용주거지역, 제1종일반주거지역,제2종일반주거지역, 제3종일반주거지역,준주거지역
  * **상업지역** : 중심상업지역, 일반상업지역, 근린상업지역, 유통상업지역
  * **공업지역** : 전용공업지역, 일반공업지역, 준공업지역
  * **녹지지역** : 보전녹지지역, 생산녹지지역, 자연녹지지역
  * **관리지역** : 계획관리지역, 생산관리지역, 보전관리지역
  * **기타지역** : 농림지역, 자연환경보전지역
  * **용도지구**: 경관지구, 고도지구, 방화지구, 방재지구, 보호지구, 취락지구, 개발진흥지구, 특정용도제한지구, 복합용도지구
  * **용도구역**: 개발제한구역, 도시자연공원구역, 시가화조정구역, 수산자원보호구역, 입지규제최소구역

***

* **매각차익 조건** : 차익유(낙찰가 < 매각가), 차익무(낙찰가 > 매각가)
* **숨은 가치 조건** : 저평가(시세 > 감정가), 고평가(시세 < 감정가)
* **수익 실현 조건** :부대비용 포함 여부 (포함/미포함)
* **시세 추정**
* **감정 시점** : 감정 시점 선택 (예: 낙찰 시점, 매각 시점 등)
* **유찰 횟수** : 예: 1회 이상, 3회 미만 등
* **노후년도** : 예: 10년 이상, 20년 미만 등
* **매각 일수** : 30일 이내, 6개월 초과 등
* **실투자금 계산**
* **특수 조건** :
  * HUG 인수 조건 변경
  * 재매각
  * 분묘기지권
  * 임차인 대항력
  * 위반 건축물
  * 유치권
  * 임금채권
  * 법정지상권
